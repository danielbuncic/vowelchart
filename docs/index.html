Vowel Chart Maker

Build a vowel chart, then download/copy it as SVG or PNG or as LATEX code for the package vowelchart; or convert LATEX code from (pst-)vowel. Everything runs in your browser.

Vowels, arrows, shapes

Everything is drawn in the order of this list: items further down lie on top of the ones above (use ↑ ↓ to change the order).
Monophthongs: type an IPA symbol or its X-SAMPA code (e.g. E, 2, @, 6') – the position comes from the IPA chart. To place a vowel yourself, fill in h (0–2, left to right) and v (0–3, top to bottom).
Diphthongs (arrows): start and end are an IPA/X-SAMPA symbol or h,v (e.g. 1,1.5).
Line, rectangle, ellipse: endpoints, corners or center are given like the end of an arrow (h,v or a symbol). A rectangle is a rectangle in vowel space (its sides follow the shape of the chart). Ellipse: the second field holds the radii rx,ry (one number = circle) in chart units. Further fields: line width, line style, fill opacity (0–1), outline color, fill color, “no fill” checkbox.

Word: Insert → Pictures → this device, with the SVG file (Microsoft 365/Word 2019 and later keeps it as a vector graphic), or paste the PNG. The SVG uses text, so the IPA font has to be installed on the computer that opens it; otherwise use the PNG. A downloaded SVG can be loaded here again to edit it, and so can LATEX code.

This chart in LATEX (package vowelchart)

Loading LATEX code (file or pasted from the clipboard): only what stands between \begin{vowelchart} and \end{vowelchart} is read. What the tool does not know is not drawn, but it is kept unchanged: as “LATEX” entries in the list (in their position), as further options (a field “Further options” appears) and inside the entries; colors, sizes and line widths are written exactly as they were in the code as long as you do not change them here. Charts of the old packages vowel/pst-vowel (\begin{vowel}, and \putvowel* in a vowelchart) can be loaded as well: the vowels with absolute coordinates are converted into ordinary vowels with relative coordinates, symbols at their IPA position into IPA vowels, and standard PSTricks arrows (\ncline, \ncarc, \nccurve with \naput etc.) into diphthong arrows between the nodes, with nodesep as “shorten” (they are not kept in the old form). Node names are kept as they are.
